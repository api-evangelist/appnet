# App.net

> App.net (ADN) was a paid, ad-free, developer-first real-time social networking and microblogging platform (2012–2017). The App.net Stream API exposed posts, users, follows, channels, private messages, files, filters, and a real-time streaming surface over OAuth 2.0. The service shut down 2017-03-14; its API documentation and SDKs remain preserved on the appdotnet GitHub organization. This file was generated by the API Evangelist enrichment pipeline from the preserved documentation.

## Status
- Service state: retired (shut down 2017-03-14)
- Live API hosts (api.app.net, developers.app.net): no longer resolve
- The app.net domain is now operated by an unrelated apps directory

## APIs
- [App.net Stream API (docs source)](https://github.com/appdotnet/api-spec): REST, OAuth 2.0, base URL https://api.app.net/stream/0/
